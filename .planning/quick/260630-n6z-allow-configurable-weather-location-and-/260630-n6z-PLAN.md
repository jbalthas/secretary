# Configurable weather location and daily home backgrounds

## Goal

Let the user update Today weather to their current or searched location, remember that choice, and rotate the Today hero background once per local calendar day.

## Tasks

1. Add a small weather preference module with persisted location data, geolocation/reverse-geocoding support, place search, forecast loading, and deterministic daily background selection.
2. Update the weather hero with accessible location controls, loading/error states, and a daily project-owned image rotation while preserving the existing layout.
3. Add focused tests and verify the production build, interaction flow, and desktop/mobile rendering.

## Acceptance

- Weather can use the browser's current position or a manually searched city/postal code.
- The selected display name and coordinates survive reloads.
- Weather requests use the selected coordinates and an automatically resolved timezone.
- The same background is stable all day and rotates on the next local date.
- Weather failure does not break the rest of Today, and controls remain keyboard/mobile accessible.
