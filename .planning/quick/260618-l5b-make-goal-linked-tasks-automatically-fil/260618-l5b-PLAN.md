# Quick Task Plan

## Goal

Show every goal that has linked tasks as a filter chip on the Tasks page, without
requiring the goal to also have a manually assigned `list_name`.

## Implementation

1. Derive a linked task's goal category from the goal title.
2. Preserve existing manually assigned task lists and goal list names.
3. Deduplicate category names so overlapping names render as a single chip.
4. Add focused unit coverage for category derivation and filtering.

## Verification

- A task linked to a goal with no `list_name` appears under a chip named after
  the goal.
- Existing task and goal list chips still work.
