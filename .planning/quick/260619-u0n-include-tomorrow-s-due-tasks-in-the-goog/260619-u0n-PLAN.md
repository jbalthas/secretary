# Quick Task: Include tomorrow's due tasks in the Google Home briefing

## Goal

Make the on-demand tomorrow briefing speak incomplete tasks due tomorrow in
addition to approved plan blocks and calendar events.

## Plan

1. Extend `build_tomorrow_speech()` to query incomplete tasks due on the
   configured local tomorrow date.
2. Merge due tasks into the spoken timeline and avoid repeating tasks already
   represented by approved scheduled blocks.
3. Add regression tests for due tasks, completed-task exclusion, deduplication,
   and the empty-state behavior.
4. Run the focused backend briefing tests.
