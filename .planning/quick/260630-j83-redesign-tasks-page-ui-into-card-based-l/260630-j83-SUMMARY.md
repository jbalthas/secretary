# Quick Task 260630-j83: Redesign Tasks page UI into card-based layout Summary

Replaced the Tasks page's flat TaskRow list with category-colored cards (gradient thumbnail + lucide icon), a "Focus now" hero for the top pending task, and a momentum ring (done/total) in the header — matching the visual language already established on the Now page (260624-kmx).

## What Was Built

**`frontend/src/lib/taskCategory.ts`** — Pure helper module, no React/fetch:
- `resolveCategory(task, goals)`: resolves a stable category key from task.list_name -> task.parent_list_name -> linked goal's list_name/parent_list_name -> `priority:${priority}` fallback. Case-insensitive, trimmed.
- `categoryVisual(category)`: maps a category key to `{ key, label, gradient, Icon }`. Explicit alias palette (work/career, personal/life/home, health/fitness/wellness, learning/study/education, finance/financial/money, errands/shopping/chores) each mapped to a lucide icon + CSS gradient using the existing type-* palette colors. `priority:*` categories map to `Flag` + red/amber/slate gradients. Unknown categories get a deterministic gradient via a char-code-sum hash (no Math.random) so the same unlisted list name always renders the same color.

**`frontend/src/components/MomentumRing.tsx`** — SVG circular progress ring (track + accent-colored progress arc via stroke-dasharray/offset), centered "{done}/{total} done" label, `aria-label="{done} of {total} tasks done"`. Handles total===0 (full neutral track, "0/0").

**`frontend/src/components/TaskCard.tsx`** — Replaces TaskRow. Copies TaskRow's optimistic-toggle + error-revert logic verbatim (localCompleted state, revert-on-catch, "Couldn't save — try again"). Layout: gradient thumbnail tile with category icon, title + meta row (due date, priority dot, Bell/Repeat icons), round checkbox toggle (stopPropagation on click/change so toggling doesn't open the drawer). `tasks-card--done` class dims the card, line-throughs the title, collapses meta to "Completed", same aria-label pattern as TaskRow.

**`frontend/src/components/TasksHero.tsx`** — Full-width hero with a gradient cover (category gradient + large translucent icon), "FOCUS" label, task title, meta line (`~{minutes} min` or priority label), "Start" button calling the passed `onStart`. New `tasks-hero` CSS family (does not reuse `now-hero` classes).

**`frontend/src/pages/Tasks.tsx`** wiring:
- Added `tasks-header` row with `<h1>` + `<MomentumRing>`. Ring uses `listFiltered` (active-chip set across both tabs) as the explicit "current visible set" definition — commented inline.
- `heroTask = filter === "pending" && sorted.length > 0 ? sorted[0] : null` — naturally hidden on Completed tab and when pending is empty; respects active chip + sort order.
- Replaced `sorted.map(task => <TaskRow .../>)` with `<div className="tasks-card-grid">` mapping to `<TaskCard>`.
- All existing state/logic untouched: `taskFilters`, `listFiltered`, `filtered`, `sorted`, `handleSave`, drawer open/save/delete, FAB.

**`frontend/src/styles.css`** — New "Tasks page — card redesign" section: `.tasks-header`, `.momentum-ring` (+ `.momentum-ring-progress` with `prefers-reduced-motion` guard), `.tasks-hero` family (cover/body/label/title/meta/action), `.tasks-card-grid` (1-col mobile, 2-col at >=640px), `.tasks-card`, `.tasks-card-thumb`, `.tasks-card-body`, `.tasks-card-title`, `.tasks-card-meta`, `.tasks-priority-dot` (+ high/medium/low modifiers), `.tasks-card-check`, `.tasks-card--done`, `.tasks-card-error`. Uses only existing CSS variables and type-* gradient colors; no new dependencies.
