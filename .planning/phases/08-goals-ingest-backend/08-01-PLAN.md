Goals API (built in Plan 03):
- POST   /api/v1/goals/                          body {title, type, description?, target_date?} -> 201 GoalRead
- GET    /api/v1/goals/                          -> 200 list[GoalRead] (includes archived)
- GET    /api/v1/goals/{id}                      -> 200 GoalRead (has progress_pct:int, milestones:list)
- PATCH  /api/v1/goals/{id}                      body {status?, title?, ...} -> 200 GoalRead
- POST   /api/v1/goals/{id}/milestones           body {title, target_date?} -> 201 MilestoneRead
- PATCH  /api/v1/goals/{id}/milestones/{ms_id}   body {done?, title?} -> 200 MilestoneRead
GoalRead fields: id, title, type, description, target_date, status, progress_pct (int), milestones (list[MilestoneRead])
GoalType values: "career" | "life" | "health" | "learning" | "financial"
GoalStatus values: "active" | "archived" | "completed"

Ingest API (built in Plan 04):
- GET  /api/v1/ingest/schema    -> 200 dict containing keys "properties" and "required"; properties includes "schema_version"
- POST /api/v1/ingest/confirm   body IngestPayload -> 200 {created:{...}, updated:{...}} | 422 on validation error

IngestPayload shape:
{ "schema_version": "1.0",
  "goals":    [{external_key, title, type, description?, target_date?, milestones?:[{title, target_date?, done?}]}],
  "tasks":    [{external_key, goal_key?, title, priority?, due_date?, description?}],
  "routines": [{external_key, goal_key?, name, cron, action?}],
  "habits":   [{external_key, goal_key?, title, recurrence_cron, priority?, description?}] }

Celebration patch target (Plan 03 fires these): app.services.celebrate.fire_milestone_celebration(milestone_title, goal_title)
and app.services.celebrate.fire_goal_celebration(goal_title). Tests monkeypatch these to assert they are/aren't called.
Patch at app.routers.goals.celebrate.<fn> OR monkeypatch app.services.celebrate.<fn> — use the latter (source module) so the patch survives the run_in_threadpool call.

Ingest rollback injection point (Plan 04 exposes this): app.services.ingest_service._upsert_task — monkeypatch to raise on the 2nd call.
