## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 (regular) | 1.5 |
| Label | 14px | 400 (regular) | 1.4 |
| Heading | 20px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

Notes:
- Body (16px/400) is the default for task row titles and agenda item titles.
- Label (14px/400) is used for due dates, time stamps, description previews, and tab labels.
- Heading (20px/600) is the page title ("Today" / "Tasks") rendered in the top bar.
- Display (28px/600) is reserved for future use (not used in Phase 2).
- All text is left-aligned except bottom nav labels (centered under icon).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #0f172a | App background (dark navy) |
| Secondary (30%) | #1e293b | Bottom nav bar, drawer surface, task row hover state |
| Accent (10%) | #6366f1 | Active nav tab indicator, FAB background, focus rings |
| Destructive | #ef4444 | Delete task button and confirmation dialog only |

**Surface rationale:** Dark theme suits a personal dashboard viewed on phone in varied lighting. The dominant/secondary split is navy (#0f172a) / slate (#1e293b) — clearly distinct without harsh contrast.

Accent (#6366f1, indigo) reserved for:
- Active bottom nav tab (icon + label tint)
- FAB button background
- Focus ring on interactive elements
- Checkbox checked state

Priority badge colors (Claude's discretion per CONTEXT.md):
- High: #ef4444 (red-500) background at 15% opacity, #ef4444 text — label "High"
- Medium: #f59e0b (amber-500) background at 15% opacity, #f59e0b text — label "Med"
- Low: #64748b (slate-500) background at 15% opacity, #94a3b8 text — label "Low"

Text colors:
- Primary text: #f1f5f9 (slate-100)
- Secondary text: #94a3b8 (slate-400) — due dates, timestamps, description previews
- Disabled/placeholder: #475569 (slate-600)
- Destructive: #ef4444

## Component Inventory

### Bottom Navigation Bar
- Fixed at viewport bottom
- Height: 56px
- Background: secondary (#1e293b), 1px top border #334155
- Two tabs: "Today" (agenda) and "Tasks" (task list)
- Active tab: accent icon + accent label; inactive: slate-400 icon + slate-400 label
- Default active on load: "Today"

### Task Row (compact)
- Full-width row, 48px min-height
- Left: checkbox (24px, rounded, accent when checked)
- Then: title (body 16px) + priority badge (12px label, pill shape, 4px×8px padding)
- Right-aligned: due date (label 14px, slate-400), reminder icon (bell, 16px) if reminder set, recurrence icon (repeat, 16px) if recurring
- Description preview: single line, 14px, slate-400, truncated with ellipsis, shown below title
- Completed tasks: title line-through, opacity 0.5
- Row tap opens edit drawer

### Pending / Completed Tabs
- Horizontal tab strip directly below page title
- "Pending" and "Completed" labels, 14px/600
- Active tab: bottom border 2px accent, accent text
- Inactive tab: slate-400 text, no border

### Sort Dropdown
- Inline with tabs, right-aligned
- Label: "Sort: Due date" or "Sort: Priority"
- 14px/400, slate-400
- On tap: native select or simple popover with two options

### Task Form Drawer
- Slides in from right edge, full viewport height, 85vw width (max 400px)
- Background: secondary (#1e293b)
- Header: "New task" or "Edit task" (heading 20px/600), X close button top-right
- Always-visible fields: title input, priority selector (3-option segmented control: High / Med / Low), due date input (date picker)
- Collapsible sections (tap to expand, default collapsed): Description, Reminder, Recurrence
- Collapsible trigger: row with chevron icon, label 14px/600
- Save button: full-width, accent background, "Save task" label
- Delete button (edit mode only): text-only, destructive color, "Delete task", below save

### FAB (Floating Action Button)
- Fixed: bottom 80px (above nav bar), right 16px
- 56px diameter circle, accent background
- Plus icon (lucide `Plus`, 24px, white)
- Box shadow: 0 4px 12px rgba(0,0,0,0.4)

### Agenda Item Row
- Same compact row style as task row
- Task items: show priority badge + due time if set
- Calendar event items (placeholder): no priority badge, show time (e.g. "9:00 AM"), italic title to distinguish from tasks
- All-day items pinned to top of list with no time shown
- Section header "All day" (label 14px/400, slate-400) above all-day block if any exist

### Empty States
- Task list empty: centered in content area, slate-400 icon (clipboard, 48px), heading + body text (see Copywriting)
- Agenda empty: same treatment, calendar icon

### Recurrence Input (Claude's discretion — simpler approach)
- Friendly picker: "Every day", "Every week", "Every month" as 3 segmented buttons
- "Custom (cron)" option opens a single-line text input for raw cron expression
- No date-picker library required; use `<input type="date">` and `<input type="time">` native elements styled with CSS

## Interaction Contracts

### Drawer Animation
- Slide in from right: translate3d(100%, 0, 0) → translate3d(0, 0, 0)
- Duration: 250ms, ease-out cubic-bezier
- Backdrop: rgba(0,0,0,0.5) fades in simultaneously
- Dismiss: tap backdrop or X button; slides out 200ms ease-in
- No body scroll lock needed — task list behind is intentionally visible

### Checkbox Complete Toggle
- Optimistic UI: check immediately, strike title, fade to 50% opacity
- Fire PATCH /api/v1/tasks/{id} in background
- On error: revert visual state, show inline error label "Couldn't save — try again"

### Delete Flow
- Tap "Delete task" in drawer → modal dialog with confirmation (not inline)
- Confirm → drawer closes, row removed from list (optimistic), DELETE /api/v1/tasks/{id} fires
- On error: re-insert row, show error toast "Couldn't delete — try again"

### Sort
- Sort is local-state only in Phase 2 (no server-side sort params required)
- Switching sort re-orders the in-memory list immediately

### Scroll
- Task list: standard scroll, no pagination needed in Phase 2
- Agenda list: same, short list expected

## Accessibility

- All interactive elements have visible focus rings (2px solid accent, 2px offset)
- Checkbox uses `<input type="checkbox">` with `aria-label`
- Drawer: focus trapped inside while open; focus returns to FAB on close
- Bottom nav: `role="navigation"`, active tab has `aria-current="page"`
- Priority badges: `aria-label="Priority: High"` (not color-only)
- Color contrast: primary text (#f1f5f9) on dominant (#0f172a) = 15.5:1 (passes AAA)
- Color contrast: secondary text (#94a3b8) on dominant (#0f172a) = 6.2:1 (passes AA)
