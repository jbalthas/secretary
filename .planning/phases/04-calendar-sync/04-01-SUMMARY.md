## User Setup Required

External service configuration required before OAuth flow will work:

- `GOOGLE_CLIENT_SECRETS_JSON` — download OAuth 2.0 client JSON from Google Cloud Console, paste as single-line string
- `GOOGLE_OAUTH_REDIRECT_URI` — must match Authorized redirect URI in Google Cloud Console
- `GOOGLE_SESSION_SECRET` — generate with `python -c "import secrets; print(secrets.token_hex(32))"`
- Enable Google Calendar API in Google Cloud Console
- Publish OAuth consent screen to "In production" (prevents 7-day token expiry)
