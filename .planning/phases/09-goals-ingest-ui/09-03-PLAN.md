Backend goal endpoints (backend/app/routers/goals.py — already live):
```
GET    /api/v1/goals/                      -> GoalRead[] (includes progress_pct + milestones)
GET    /api/v1/goals/{id}                  -> GoalRead
POST   /api/v1/goals/                      -> 201 GoalRead   (GoalCreate; omit external_key for manual goals)
PATCH  /api/v1/goals/{id}                  -> GoalRead       (status=archived to archive; status=completed fires celebration)
POST   /api/v1/goals/{id}/milestones       -> 201 MilestoneRead   (MilestoneCreate {title, target_date?})
PATCH  /api/v1/goals/{id}/milestones/{ms}  -> MilestoneRead       ({done:true} fires celebration)
```
