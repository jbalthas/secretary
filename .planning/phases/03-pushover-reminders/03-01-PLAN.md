PushoverClient (backend/app/services/pushover.py — built in Plan 02):
  class PushoverClient:
      def send(self, title: str, message: str, priority: int = 0) -> None
  - POSTs to "https://api.pushover.net/1/messages.json"
  - data fields: token, user, title, message, priority
  - empty message ("" or None) sent as a single space " " (Pushover rejects blank)
  - calls r.raise_for_status()

scheduler module (backend/app/scheduler.py — built in Plan 02):
  scheduler: AsyncIOScheduler                      # module-level singleton
  def upsert_reminder(task) -> None                # adds DateTrigger job id=f"reminder_task_{task.id}", replace_existing=True; if task.reminder_at is None -> remove_reminder(task.id)
  def remove_reminder(task_id: int) -> None        # scheduler.remove_job; swallow JobLookupError
  def _pushover_priority(priority) -> int          # high -> 1, medium/low/None -> 0
  - job id convention: f"reminder_task_{task_id}"
</contracts>
