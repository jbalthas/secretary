HARD CONSTRAINTS (locked, non-negotiable):
- Apply path REUSES `ingest_service`: build goal/milestone rows, `await session.flush()`, build
  `goal_key_to_id`, then for each new task call `ingest_service._upsert_task(...)` directly.
  Apply order goals -> milestones -> tasks. NO duplication of _upsert_task's body.
- Atomicity via a SINGLE `async with session.begin():` around the whole apply.
- Idempotency: at the top, `SELECT AdvisoryLog WHERE advisory_id == request.advisory_id`; if
  found, return the stored `AdvisoryResult` (deserialize result_json) and apply NOTHING. Else
  apply, then `session.add(AdvisoryLog(advisory_id=..., result_json=<serialized result>))`
  inside the same transaction.
- New-task stable external_key: `f"advisory-{advisory_id}-{i}"` (i = index in new_tasks) so
  re-confirm resolves the SAME row via Task.external_key UNIQUE.
- Goal match by external_key; milestone match by compound `(goal_id, title)` (inline query —
  the generic _exists helper does not support compound keys).
- `payload.notes` is DISPLAY-ONLY — NEVER written to any entity field.
- Stamp `AppSettings.last_advisory_at = now` inside the apply transaction.
- Async on AsyncSession (get_session pattern), NOT the sync export path. NO LLM imports.

      - goals diff: for each GoalAdjustment, SELECT Goal by external_key. If absent ->

        Else build AdvisoryEntityDiff(action="update", external_key, title=goal.title,

        Only include a field-change when the adjustment supplies that field (not None).
      - milestones diff: resolve goal by goal_external_key (ValueError if unknown), then
        SELECT Milestone WHERE goal_id == goal.id AND title == a.title. If absent -> ValueError
        (unknown milestone). Else build AdvisoryEntityDiff(action="update", ...) with field
        changes for target_date/done.
      - new_tasks diff: each is action="create"; AdvisoryEntityDiff(external_key=
        f"advisory-<preview>-{i}", title=t.title, action="create", rationale=t.rationale,
        fields=[new-only AdvisoryFieldChange(field, None, value) for title/priority/due_date/
        estimated_minutes/description present]). Validate goal_external_key resolves -> else ValueError.
      - return AdvisoryPreviewResult(goals, milestones, new_tasks, notes=payload.notes,

    `apply_advisory(req, session)` (atomic + idempotent):
      - seen = await session.execute(select(AdvisoryLog).where(AdvisoryLog.advisory_id == req.advisory_id))
        row = seen.scalar_one_or_none()
        if row is not None: return AdvisoryResult(**json.loads(row.result_json), replayed=True)
      - async with session.begin():
          created = {"goals":0,"milestones":0,"tasks":0}; updated = {...0}
          # GOALS
          for a in req.payload.goal_adjustments:
              g = (await session.execute(select(Goal).where(Goal.external_key==a.external_key))).scalar_one_or_none()
              if g is None: raise ValueError(f"unknown goal external_key: {a.external_key}")
              if a.target_date is not None: g.target_date = a.target_date
              if a.priority_rank is not None: g.priority_rank = a.priority_rank
              updated["goals"] += 1
          await session.flush()
          goal_key_to_id = build from the goals touched + any goals referenced by milestones/tasks
              (SELECT id by external_key as needed; reuse the flushed rows).
          # MILESTONES
          for m in req.payload.milestone_adjustments:
              goal_id = goal_key_to_id resolve (SELECT Goal by m.goal_external_key if not cached; ValueError if unknown)
              ms = (await session.execute(select(Milestone).where(Milestone.goal_id==goal_id, Milestone.title==m.title))).scalar_one_or_none()
              if ms is None: raise ValueError(f"unknown milestone: {m.goal_external_key}/{m.title}")
              if m.target_date is not None: ms.target_date = m.target_date
              if m.done is not None: ms.done = m.done
              updated["milestones"] += 1
          # NEW TASKS (reuse _upsert_task, no fork)
          for i, t in enumerate(req.payload.new_tasks):
              goal_id = goal_key_to_id resolve by t.goal_external_key (ValueError if unknown)
              ti = TaskImport(external_key=f"advisory-{req.advisory_id}-{i}", title=t.title,
                   description=t.description, priority=t.priority, due_date=t.due_date,
                   ...map remaining TaskImport fields, defaults for absent)
              _, was_created = await ingest_service._upsert_task(ti, goal_id, session)
              (created if was_created else updated)["tasks"] += 1
          # STAMP last_advisory_at
          settings_row = (await session.execute(select(AppSettings).limit(1))).scalar_one_or_none()
          if settings_row is not None: settings_row.last_advisory_at = datetime.now(timezone.utc)
          result = AdvisoryResult(created=created, updated=updated, advisory_id=req.advisory_id, replayed=False)
          session.add(AdvisoryLog(advisory_id=req.advisory_id, result_json=result.model_dump_json(exclude={"replayed"})))
      - return result
      NOTE: payload.notes is read ONLY for the preview response; it is NEVER assigned here.
