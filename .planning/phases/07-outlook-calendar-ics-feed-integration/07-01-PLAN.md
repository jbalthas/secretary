    `_make_fixture(base: date | None = None, include_timed: bool = True) -> bytes`

    When `base` is None, default `base = date.today() + timedelta(days=7)` so all events
    land ~1 week out — well inside the 90-day window regardless of run date. The helper
    returns VCALENDAR bytes containing:

      SUMMARY Labor Day

      `RRULE:FREQ=WEEKLY;COUNT=4` (occurrences at base, base+7, base+14, base+21), one

      in-window occurrences, SUMMARY Weekly Lab
