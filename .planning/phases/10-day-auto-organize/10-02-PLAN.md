    - `due = task.due_date.date() if task.due_date else None`

First-fit: scan gap_cursors for first (cursor, end) with `end - cursor >= duration`; place block at cursor..cursor+duration, set gap_cursors[i] = (block_end, end), append ProposedBlock(task_id=task.id, title=task.title, start_dt=block_start, end_dt=block_end). If none fit, add task to unplaced.
