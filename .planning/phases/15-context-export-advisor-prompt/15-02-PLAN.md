    `build_export_bundle() -> dict`:
        session_id = str(uuid.uuid4()); generated_at = datetime.now(timezone.utc).isoformat()
        today = date.today()
        with _Session() as s:
          - Query active goals: select(Goal).where(Goal.status == GoalStatus.active)
          - Order career/learning first (D-04/D-06):
                goals = sorted(goals, key=lambda g: (
                    g.type.value not in PRIORITY_TYPES, g.target_date is None, g.target_date or date.max))
          - For each goal render a section (INSIDE the session -- lazy="selectin" needs it):
              * title, type.value, target_date, days_remaining =
                  (g.target_date - today).days if g.target_date else None
              * progress = _compute_progress_sync(g.id, s)   # D-03 live, NOT from snapshots
              * milestones: list g.milestones (title + done)
              * top-3 active tasks: [t for t in g.tasks if not t.completed], sorted by
                  (-PRIORITY_RANK[t.priority.value], due_date or datetime.max), take 3 -> title/priority/due
              * overdue count: sum(1 for t in g.tasks if not t.completed and t.due_date and
                  t.due_date < datetime.now()); render literal word "overdue" + count
              * trend: GoalProgressSnapshot rows for g.id ordered snapshotted_on ASC, last 4;
                  render the up-to-4 progress_pct values and append _velocity_label(rows). If zero
                  rows -> render "no_data".
          - 14-day block summary (EXPORT-03): query ScheduledBlock where
                date_key >= (today - timedelta(days=14)).isoformat() and date_key <= today.isoformat().
                planned=len; completed=sum(b.completed); slipped=sum(not b.completed and
                b.date_key < today.isoformat()). Render a small Markdown table.
          - 7-day calendar load (EXPORT-05, PRIVACY D-05): query CalendarEvent where
                cancelled == False and the event date is within [today, today+6]. Branch on all_day:
                all-day uses start_date ("YYYY-MM-DD"); timed uses start_dt.date(). Group by date,
                COUNT events per day. Render per-day counts ONLY -- NEVER event titles.
          - Stalled goals (EXPORT-05): stalled = _find_stalled_goals(s, 7) (open session).
                Render goal titles under a "## Stalled Goals" header (title only).
        # assemble markdown
        lines = ["# Advisor Brief",
                 f"generated_at: {generated_at}  session_id: {session_id}", "",
                 "## Goals", *goal_sections, "",
                 "## 14-Day Block Summary", block_table, "",
                 "## 7-Day Calendar Load", calendar_section, "",
                 "## Stalled Goals", stalled_section]
        markdown = "\n".join(lines)

        Token budget (D-06/D-07): if len(markdown) // 4 > TOKEN_BUDGET, apply truncation in order:
        (1) collapse the block summary to bare counts, (2) cap tasks per goal at 3 (already the
        default), (3) truncate each trend to its 2 most recent values; reassemble. NEVER drop a
        whole goal. For a single-user app this path is rarely hit -- a simple post-assembly length
        check that re-renders with a `compact=True` flag is sufficient.

        return {"markdown": markdown, "session_id": session_id, "generated_at": generated_at}

    Use small private `_render_*` helpers as convenient (Claude's discretion on exact table
